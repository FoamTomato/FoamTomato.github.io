openFeign引入失败

发表于2022-08-22|更新于2026-07-06|中间件与架构
|浏览量:

最近用nacos集成openFeign的时候，遇到一直引入不了依赖

一开始以为是maven源的问题，所以加了特别多的仓库都没有解决，后面试着加版本号，没想到就解决了

而且在启动类中也可使用@EnableFeignClients注解
