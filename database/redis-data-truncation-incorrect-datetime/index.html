|浏览量:

最近在编写项目时，用redis存储结果一直报转换异常

对此我有了以下思路
1.在mysql进行格式转换
2.在java先转换
3.存json之前就进行格式转换

但是以上方法都不行，因为数据需要的是date类型，如果走转换又过慢

有大佬提了一下使用序列化解决，我就尝试了一下，还真可以,以下是我编写思路
1.首先需要序列化的类继承Serializable接口

2.编写序列化工具类

3.使用序列化存储


4.反序列化读取

第一个红框是我用gson进行json转换
第二个红框是序列化后强转为原对象
